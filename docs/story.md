# 脉络 Mailuo：把聊天截图变成人脉档案

> 状态：Android 安装包 v3.1.15（2026 年 9 月 4 日），BYOK 单机版，数据只存手机；网页版支持连接自己部署的服务器。开源，MIT 协议。
> 入口：[GitHub 仓库](https://github.com/AliceLJY/mailuo) · [下载安装包](https://github.com/AliceLJY/mailuo/releases/latest)

## 它解决什么

在微信里谈事的人都有同一个麻烦：约了谁、几号见、对方换了公司、上次聊到哪，全散在聊天记录里，回头翻不过来。CRM 解决不了这件事，因为没人愿意录入。

脉络把录入压缩成截一张图。把聊天截图丢进去，它先认出截图里的人、约定和事实，整理成一张张可以编辑的卡片；我逐张确认，确认过的内容才写进档案。截图是一次性的，看完就可以扔；截图里的人是持续的，档案越滚越厚，关系的变化才看得见。每一条「洞察」都必须指向档案里已有的某条观察记录，不允许看一张图即兴发挥。

## 起点：一道 48 小时的题

2026 年 8 月 26 日，我拿到一道 agent 产品的限时作业题：用户上传聊天截图，系统生成可确认的行动卡片，确认后结合历史档案给出洞察。题目里有两个提示我抓住了：「不是 API 套壳」和「怎么处理 memory」。截图理解谁都能调模型做，真正考的是数据怎么组织、人怎么参与。

所以核心设计定为「按人头建档」：每张截图抽出来的信息，全部挂到「这个人」的档案下面。这就是我对 memory 那一问的回答。

48 小时内交了两个版本。v1 是完整的自部署版：公开仓库、安卓安装包、iPhone 网页版、生产部署。v2 是真机测试时我自己问出来的：「别人下载了安装包，连的是谁的电脑？」于是推出 BYOK 单机版，普通人填一个模型 Key 就能用，不需要任何服务器。

题交完之后没有停。v3 把「识字」和「理解」拆开：手机本地 OCR 先读图，再让文本模型把带标注的文字整理成结构化证据，原始截图默认不出手机。到 v3.1.15，一共 130 次提交、19 个版本号，跨度 12 天。

## 几个关键取舍

- **宁可留空，不要猜错。** 气泡底色判不出就告警，不猜；联系人拿不准就问，不自动合并；时间只有「明天」没有绝对日期，就留空。
- **日历算术不交给模型。** 「下周三下午三点」模型反复算错，喂它 14 天的日期对照表还是错。两轮之后判这条路死刑，改成一百来行代码解析中文时间，零成本、永不出错。该模型做的是理解与判断，该代码做的是计算与校验。
- **记忆分三层。** 感觉层存截图的原始抽取，只用于溯源；工作层是等待确认的卡片；长期层是联系人、观察记录、事项和洞察。档案字段只在人确认后更新，观察记录只追加不改写，每条锚定原文和时间。
- **一个安装包，三种用法。** 填自己的模型 Key 单机跑、连自己部署的服务器、订阅占位。Key 只进系统钥匙串，界面永远不回显全文。

## 怎么做出来的

这个项目通过 AI 协作完成。Claude 负责设计图纸、拆里程碑、写每一批的交接材料和验收标准；Codex 按图纸施工；我做全部选择题：需求定义、九次设计与范围分歧的裁决、验收标准，以及真机测试。

每一批代码都要过三层测试才算数：mock 层锁住行为，真模型层抓 prompt 问题，真机层抓平台和交互问题。真模型层抓出过四个 mock 看不见的问题：把我自己的发言建成联系人、把换公司写错字段、把客套话生成会议、把洞察 JSON 截断。

## 踩过的坑

- **AI 说「测试全绿」，绿在另一个世界。** 第一批代码汇报 17 个测试全过，在真实机器重跑，9 个失败。它发现机器上没有图纸要求的 Node 版本，自己临时下载了一个来跑测试。它没撒谎，只是「测试通过」省略了「在哪通过」。从此验收一律在真实环境重跑。整个 48 小时盘下来，「报告成功但实际没成」一共六次。
- **真机第一天就是用户测试。** 「澄曜实验室」被认成「潜曜实验室」，同一张图前一天在命令行是对的。小概率错误拦不住，但可以让它在写进档案前经过人的眼睛，这正是确认流存在的理由。
- **一个问题变成一个版本。** 我随口问「为什么要两个 API Key，一个不行吗」，追下去发现同一个服务商名下既有视觉模型也有文本模型，于是第二个 Key 从必需变成选填。从提出到上线，六小时。
- **八个小版本靠诊断包驱动。** v3.1.7 到 v3.1.15，app 把行动卡、逐截图 trace、事件日志、崩溃堆栈导出到我自选的文件夹，不上传任何内容；互动记录的规则按我每轮实际拒掉的卡逐轮收紧。

## 现在的边界

- 本地 OCR 仍可能认错字，重要字段要在卡片上人工核对。
- 事项查重有意保守，可能漏掉相似项；整张截图的去重还没做。
- 它不是「全离线」：推理时识别出的文字会发给我配置的模型服务商，原始截图默认留在手机；只有本地 OCR 失败或我强制云端视觉时，截图才会发给视觉模型。隐私边界在 README 里逐条写清。
- 单用户，没有多用户鉴权；iOS 原生分发要等开发者账号。
